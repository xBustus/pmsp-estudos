Política de Privacidade

PMSP Estudos · última atualização: 14 de novembro de 2026

O PMSP Estudos é um aplicativo pessoal que roda localmente no computador do próprio usuário. Esta política explica como ele trata os dados da Conta do Google quando a integração com o Google Agenda é ativada.

Dados acessados

O app solicita somente o escopo https://www.googleapis.com/auth/calendar.app.created. Ele permite criar agendas secundárias e ver, criar, alterar e excluir eventos apenas nas agendas criadas pelo próprio app. O app não lê nem altera outras agendas, contatos, e-mails ou quaisquer outros dados da Conta do Google.

Como os dados são usados

Os dados são usados exclusivamente para criar e manter atualizada a agenda de estudos do usuário no Google Agenda. Eles não são usados para publicidade, análise, perfilamento ou qualquer outra finalidade.

Armazenamento

Os tokens de autorização e os dados do cronograma ficam armazenados somente no computador do usuário. O app não possui servidores e não envia dados a terceiros; a única comunicação externa é com as APIs do Google, para criar e atualizar a agenda.

Compartilhamento

Nenhum dado é vendido, transferido ou compartilhado com terceiros.

Uso Limitado

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguirão a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. A agenda criada pelo app pode ser excluída diretamente no Google Agenda.

Contato

Dúvidas sobre esta política podem ser enviadas pelo e-mail de suporte exibido na tela de consentimento do Google.
